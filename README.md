# Pizzabot

In this assignment we had to create a pizzabot where the visitor will order food.
They can choose from pizza, pasta and salad and they have to verify their age as well before they continue with the purchase.

I started out trying to mimic the demo, and I noticed that due to the comments in the code it was very easy getting some help from VS code to move along.
I also asked Copilot to explain some parts of the code to me, since I had some issues with setting upp the different choices.
But I think I got the hang of it in the end, and will definitely try it out more.
However I would have liked to make this ordering service with a lot fewer clicks, but I took some time to add default choices if the wrong inputs where made and I also added a verification on the age confirmation.
